# 📦 Distribution & Packaging Guide for halpradio

This document outlines the packaging specifications, community distribution channels, and registry instructions for **halpradio**.

Published today: the GitHub release assets (archives, `.deb` packages, `checksums.txt`) and the Homebrew tap. The APT repository is built but not yet served, no container image is published, and the AUR, Scoop and Nix entries below are templates for packagers, not published packages.

Whatever you package, take hashes from the release's `checksums.txt` and check that file first (see [SECURITY.md](../SECURITY.md#verifying-a-download)). Never ship a recipe that skips verification (`SKIP`, missing `hash`).

## 🔏 Install script and signatures

Signatures: every release after v0.8.1 publishes `checksums.txt.sigstore.json`, a Sigstore bundle for `checksums.txt` made by the release workflow. v0.8.1 and older releases have no signature.

The installer (`install.sh`) always checks the archive's SHA-256 against `checksums.txt` and stops on a mismatch. With `cosign` installed it also checks the signature (the certificate must name `.github/workflows/release.yml` of `halpworld/halpradio` at that exact tag, issuer `https://token.actions.githubusercontent.com`):

| Situation | Result |
|---|---|
| Signature present and it verifies | Installs; reports "verified with cosign". |
| Signature present but it does not verify | Stops. No variable changes this. |
| Signature missing or cannot be downloaded, release after v0.8.1 | Stops, unless `HALPRADIO_ALLOW_UNSIGNED=1` (then installs with a warning). |
| Signature missing, v0.8.1 or older | Installs on the checksum only and says the release predates signing. |
| `cosign` not installed | Installs on the checksum only and says the signature was NOT checked. |

Environment variables:

- `VERSION=vX.Y.Z` installs that release instead of the latest.
- `INSTALL_DIR=<dir>` installs into that directory (default `/usr/local/bin`, falling back to `~/.local/bin`).
- `HALPRADIO_REQUIRE_SIGNATURE=1` stops unless the signature was verified, for every version: also when `cosign` is not installed or the release is v0.8.1 or older. It wins over `HALPRADIO_ALLOW_UNSIGNED`.
- `HALPRADIO_ALLOW_UNSIGNED=1` (only matters with `cosign` installed) continues with a warning when a release after v0.8.1 has no usable signature. It never accepts a signature that fails to verify.

## 🍺 Homebrew (macOS & Linux)

### Official Tap Formula
`halpradio` is distributed via the official tap [`halpworld/homebrew-tap`](https://github.com/halpworld/homebrew-tap):

```bash
brew install halpworld/tap/halpradio
```

The formula in the tap is generated by `.goreleaser.yaml` on each tagged release and pins the SHA-256 of every archive. No bottles are built; Homebrew installs the prebuilt release binary. There is no formula in this repository.

## 🍥 Debian / Ubuntu / Linux Mint / Pop!_OS (APT)

`halpradio` provides native `.deb` packages on every release. The release workflow also builds a GPG-signed APT repository on the `gh-pages` branch.

### 1. Official APT Repository

> **Not yet available.** GitHub Pages is not enabled for the repository yet, so `https://halpworld.github.io/halpradio/` returns 404 and the commands below fail. Use the standalone `.deb` until it is live.

The repository only ever contains the packages of the latest release: each release rebuilds it from that release's `.deb` files, checked against the release's `checksums.txt`, and signs it with the archive key (primary key fingerprint `B2B5 AB26 19FF 9D6A 7EA6  30CA 79E3 1FF2 2916 CAAE`).

The signed `Release`/`InRelease` file carries `Valid-Until`, 14 days after its `Date` (`APT_VALID_DAYS` in `scripts/build_apt_repo.sh`). After that date `apt update` rejects the index as expired, which stops an attacker from replaying an old, signed index. The release workflow only re-signs when a release is made, so a scheduled job that rebuilds and re-signs the repository from the latest release at least every 14 days is needed before the repository goes live; it does not exist yet.

> **Owner action before the APT repository is announced:** the key committed under `keys/` (`B2B5 AB26 19FF 9D6A 7EA6  30CA 79E3 1FF2 2916 CAAE`) is the old archive key, and it has no expiry date. Rotate it with `scripts/setup_apt_gpg.sh` (new key with an expiring signing subkey, new `keys/` files, `APT_SIGNING_KEY_FPR` in `.github/workflows/release.yml`, new `GPG_PRIVATE_KEY` secret) and publish the new fingerprint here and in SECURITY.md first.

Once it is live, to install `halpradio` and receive updates via `apt upgrade`:

```bash
# 1. Download the official GPG archive signing key
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://halpworld.github.io/halpradio/halpradio-archive-keyring.gpg | sudo tee /etc/apt/keyrings/halpradio-archive-keyring.gpg > /dev/null
gpg --show-keys /etc/apt/keyrings/halpradio-archive-keyring.gpg   # compare the fingerprint above

# 2. Add the halpradio repository to your APT sources
echo "deb [signed-by=/etc/apt/keyrings/halpradio-archive-keyring.gpg] https://halpworld.github.io/halpradio stable main" | sudo tee /etc/apt/sources.list.d/halpradio.list

# 3. Update and install
sudo apt update
sudo apt install halpradio
```

### 2. Standalone `.deb` Package Download

Every release produces standalone `.deb` packages for `amd64` and `arm64`:

```bash
# Download the .deb (amd64) and the release checksums
curl --proto '=https' --tlsv1.2 -fsSLO https://github.com/halpworld/halpradio/releases/download/v0.8.1/halpradio_0.8.1_linux_amd64.deb
curl --proto '=https' --tlsv1.2 -fsSLO https://github.com/halpworld/halpradio/releases/download/v0.8.1/checksums.txt

# Verify, then install (apt resolves recommended dependencies like mpv)
sha256sum --ignore-missing -c checksums.txt
sudo apt install ./halpradio_0.8.1_linux_amd64.deb
```

## 🐧 Arch Linux (AUR)

### PKGBUILD Template (`halpradio-bin`)

Template for an Arch Linux binary package (not currently published on the AUR). Replace each checksum with the value for that file from the release's `checksums.txt`; `makepkg` then refuses a download that does not match:

```bash
# Maintainer: halpworld <https://github.com/halpworld>
pkgname=halpradio-bin
pkgver=0.8.1
pkgrel=1
pkgdesc="LazyVim-inspired Terminal Internet Radio Streamer"
arch=('x86_64' 'aarch64')
url="https://github.com/halpworld/halpradio"
license=('GPL-3.0-or-later')
optdepends=(
    'mpv: Recommended audio backend for AAC/OGG/HLS support'
    'vlc: Alternative audio backend'
)
provides=('halpradio')
conflicts=('halpradio')

source_x86_64=("https://github.com/halpworld/halpradio/releases/download/v${pkgver}/halpradio_${pkgver}_linux_amd64.tar.gz")
source_aarch64=("https://github.com/halpworld/halpradio/releases/download/v${pkgver}/halpradio_${pkgver}_linux_arm64.tar.gz")
# Copy from checksums.txt of the same release. Never use 'SKIP'.
sha256sums_x86_64=('<sha256 of halpradio_${pkgver}_linux_amd64.tar.gz>')
sha256sums_aarch64=('<sha256 of halpradio_${pkgver}_linux_arm64.tar.gz>')

package() {
    install -Dm755 "${srcdir}/halpradio" "${pkgdir}/usr/bin/halpradio"
    install -Dm644 "${srcdir}/README.md" "${pkgdir}/usr/share/doc/${pkgname}/README.md"
    install -Dm644 "${srcdir}/LICENSE" "${pkgdir}/usr/share/licenses/${pkgname}/LICENSE"
}
```

## 🐳 Docker Container

No container image is published. Build one locally from the repository's [`Dockerfile`](../Dockerfile) (multi-stage; base images pinned by digest; runs as the unprivileged `radio` user in the `audio` group) and run it with audio mapped to the host's ALSA device:

```bash
docker build --build-arg VERSION="$(git describe --tags --always)" -t halpradio .
docker run --rm -it \
  --device /dev/snd \
  --group-add "$(getent group audio | cut -d: -f3)" \
  -e TERM="$TERM" \
  halpradio
```

Do not pull a `halpradio` image from a public registry: none is published by this project.

## ❄️ Nix / Nixpkgs

Template derivation (not currently in nixpkgs). Both hashes are placeholders that make the build fail until you put in the values Nix reports; never disable them.

```nix
{ lib, buildGoModule, fetchFromGitHub }:

buildGoModule rec {
  pname = "halpradio";
  version = "0.8.1";

  src = fetchFromGitHub {
    owner = "halpworld";
    repo = "halpradio";
    rev = "v${version}";
    hash = lib.fakeHash; # replace with the hash Nix reports
  };

  vendorHash = lib.fakeHash; # replace with the hash Nix reports

  meta = with lib; {
    description = "LazyVim-inspired Terminal Internet Radio Streamer";
    homepage = "https://github.com/halpworld/halpradio";
    license = licenses.gpl3Plus;
    maintainers = [ ];
    mainProgram = "halpradio";
  };
}
```
