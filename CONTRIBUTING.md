# Contributing to halpradio 📻

Thank you for your interest in contributing to **halpradio**! We welcome station additions, bug fixes, new features, UI improvements, and documentation enhancements.

---

## 🚀 Ways to Contribute

### 1. 📻 Add New Radio Stations to the Public Catalog
Contributing new stations takes less than 30 seconds:
1. Run `halpradio`.
2. Highlight any station and press `p` (copies formatted YAML to clipboard).
3. Paste the snippet into [`stations.yaml`](./stations.yaml) and open a Pull Request!

See [Station Management Documentation](./docs/STATION_MANAGEMENT.md) for full details.

---

### 2. 💻 Code & Feature Contributions
We welcome improvements to the TUI, audio playback engines, themes, keymaps, and performance.
- Read our [Developer Contribution Guide](./docs/CONTRIBUTING.md) for setup and guidelines.
- Explore the [Architecture Overview](./docs/ARCHITECTURE.md) to learn how state and UI components are structured.
